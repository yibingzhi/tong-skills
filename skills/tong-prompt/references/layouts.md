# 布局（先结构，后材质）

读这一页是因为要落笔，不是浏览风格目录。一次只用一套。

## 静帧 `image`

**认得出什么**写进 `anchor:`，再选布局：

| 用途 | 结构 | 环境上限 |
|---|---|---|
| 神话 / 博物志单只 | 主体居中或略偏，站在一个道具上 | 2（如古松 + 薄雾） |
| 封面 / 电影静帧 | 前景主体、中景支撑、远处一块暗 | 2 |
| 信息图 `info` | 主路径 ≤7 步，大字，一张一个机制 | 0 个风景道具 |

材质只写作者要的那一派能执行的约束：绢本矿彩、厚堆笔触、烟中一道光。不要写「精品」。

图上文字整句粘贴，不让模型润色。

## 视频 `video`

正文必须能回答三件事：几秒、机位怎么动、第一帧和最后一帧各看见什么。

```text
duration: 5s
start: 独足毕方立在燃松上，喙闭合
motion: 绕松树缓慢环拍，烟向镜头右侧走
end: 喙喷出一条细火，松针仍在烧
```

不要把静帧那堆画派词再抄一遍当运动。画派仍只写一种。
