# 禁用词与替换

脚本 `scripts/scan.py` 扫的是硬伤子集。这里给人改稿用，多一点上下文。不要把第九节口癖往每篇里撒。

## 出现即修

| 表达 | 问题 | 修法 |
|---|---|---|
| 值得注意的是 / 不难发现 / 需要指出的是 | 宣布重要 | 直接说内容 |
| 综上所述 / 总而言之 / 总的来说 | 总结腔 | 删，用动作或场景收 |
| 在当今…的时代 / 随着技术的不断进步 | 教科书开头 | 从一件具体的事进 |
| 让我们来看看 / 接下来让我们 | 导游腔 | 删，直接进入 |
| 先说答案 / 掰开了揉碎了 / 你品一下 | 科普区套话 | 删 |
| 说白了 / 这意味着 / 意味着什么 / 本质上 | 现成深刻 | 删或改成具体判断 |
| 不可否认 / 毋庸置疑 / 众所周知 | 填充 | 删 |
| 赋能 / 一站式 / 形成闭环 / 增长闭环 | 空jargon | 换成这个场景里实际发生的事 |
| 某个AI工具 / 某个模型 | 空泛 | 写具体名字，不知道就问 |
| 相关研究表明 / 大量实践证明 / 据某报告 | 假权威 | 有出处就写出处，没有就删 |
| 命运的齿轮 / 如沐春风 / 梨花带雨 | 陈词滥调 | 白描或删 |

## 术语 or 空话（脚本报 WARN，人判）

闭环、抓手、本质上、对齐、颗粒度、底层逻辑、这意味着、不仅仅是

判法：删掉这个词，句子还剩不剩具体内容。「温控闭环调稳了」留；「打通业务闭环」删。「本质上」几乎总能删。

## 小说和高情绪段落

出现即换具体动作，不要用近义词续命：

- 情态：仿佛、犹如、宛若、一丝、一抹
- 动作：深吸一口气、缓缓、不禁
- 表情：眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩
- 心理：心中一动、心头一震、心下了然、心中暗道、心底泛起
- 判断：不容置疑、不易察觉、显而易见

`轻轻 / 微微 / 淡淡 / 突然 / 好像` 只在一段里堆着用时才动。角色口语、真突发、视角不确定可以留。

## 连接词（一篇里超过两处再砍）

此外、同时、进一步来说、换言之、由此可见、一方面 / 另一方面、首先 / 其次 / 最后

「首先 + 其次 + 最后」三件套同篇出现，脚本会打。单独一个「最后」不要当命中。

## 堆叠副词（同一段重复才打）

极其、极度、猛地、死死、狠狠、稳稳、生生、硬生生、瞬间、下一秒、紧接着、骤然

一段里同一个词出现两次，或这类词挤在一段里，留最必要的一处。

## 英文混排里的高频词

crucial, delve, enduring, foster, garner, intricacies, landscape, showcase, tapestry, testament, underscore, vibrant

能删就删，要留就换成这个领域的普通词。

## 替换方向

| 原文 | 方向 | 例 |
|---|---|---|
| 抽象情绪 | 身体或动作 | 紧张 → 手在抖（原文有手才写手） |
| 感到 XX | 外化 | 感到愤怒 → 攥紧拳头 |
| 形容词堆砌 | 留一个或改动词 | 美丽动人的笑容 → 她笑了 |
| 不是 A 而是 B | 先判毒 | 见 structures.md |
| 白色的药片 | 删多余修饰 | 药片 |

## 不要做的「活人感」

不要为了像人而加「怎么说呢 / 我寻思 / 不是哥们」。那是另一套模板。作者本来就这么说话才留。
