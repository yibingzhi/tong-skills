# 栏目纪律

冲突时以栏目为准，不以通用去味表为准。

## 标点

| 栏目 | `--lane` | 冒号 | 破折号 | 弯引号 / `"` |
|---|---|---|---|---|
| 普通润色 | `general` | 不禁 | ≤2 | 不禁 |
| 公众号长文 | `wechat` | 0 | 0 | 0，引用用「」 |
| 每日速览 | `brief` | ≤2 | 0 | 0 |
| 小红书 | `xhs` | 不禁 | 0 | 0 |

`13:11` 和 `https://` 里的冒号不算。

## 表情

- 长文：每段 ≤1–2，只放情绪高点。叙述段可以一个都没有。
- 速览：每段 ≤2。
- 小红书：按平台习惯。
- 禁止每段末尾挂同一个表情代替标点。

## 速览读者

`brief` 面向泛人群。行业黑话要么解释一句，要么删。不要写成给同事看的备忘。具体哪些词不能出现，属于各号自己的家规，见下一节。

## 家规文件

每个号自己的红线放本地文件，用 `--rules FILE` 传给 `scan.py`，不进 skill、不进公开仓。

```text
# 一行一条。命中算 FAIL。
某内部项目代号
我们公司
re:我(写|搭)的(接口|脚本)
re:欢迎.{0,4}打脸
```

- 普通行：按原文字面匹配
- `re:` 行：正则
- `#` 行：注释

被审核毙过两次的同类句式，就加进来。这样同一句话不用被人再说第三遍。

## CTA 黑名单

放话了 / 欢迎打脸 / 来打脸 / 看我笑话 / 回来谢我 / 不信邪 / 不服来战 / 评论区聊聊 / 点个在看 / 星标 / 关注我不迷路 / 长按扫码 / 转发给你

换皮也不行。结尾落在一个具体动作，或一句没说完的实话。

## 数字

写进稿子的数字要有来处：用户给的、日志里的、命令输出的。脑补「23 万字」这种会直接穿帮。没有数就写「不少 / 一大截」，不要装精确。
