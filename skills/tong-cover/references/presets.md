# 预设与版式

颜色默认按星期走，不要让用户选。只有用户点名 `--preset` 才覆盖。

| 星期 | preset | 氛围 |
|---|---|---|
| 一 | `dusk` | 夜空金月 |
| 二 | `twilight` | 暮光奶油 |
| 三 | `paper` | 宣纸朱印 |
| 四 | `frost` | 霜蓝 |
| 五 | `ember` | 烬暖 |
| 六 | `ink` | 墨青 |
| 日 | `dawn` | 浅金 |

| layout | 结构 | 默认比例 |
|---|---|---|
| `feed` | 信息流。大日期 + 星期 + 栏目名 | `2.35:1` |
| `editorial` | 刊头。字在左，月/云在右 | `4:3` |
| `briefing` | 竖版简报。报名 + 日期 + 三条要闻 | `3:4` |
| `divider` | 分割条。大号 `01` + 章节名 | `4:1` |
| `quote` | 金句卡。悬浮投影卡片，支持 7 大模板 | `3:4` (支持 `1:1`, `9:16`, `16:9`) |
| `bullet` | 横版清单。胶囊序号 + 要点 | `4:3` |
| `square` | 方图。日期 + 栏目 | `1:1` |
| `poster` / `story` | 旧名，等于 `briefing` | `3:4` |
| `banner` | 宽图；公众号封面请用 `feed` | `16:9` |

### 金句卡风格 (`--style`)

- `paper`：温润米白纸张底色 + 悬浮纸质投影 + 典雅宋体 + 朱红印章。适合经典箴言、深度思考。
- `editorial`：高对比黑白 + 现代粗黑体 + 粗细双横线 + 分类胶囊标签 + 装饰条码。适合商业洞察、职场金句。
- `highlight`：暖黄护眼底 + 模拟微信读书荧光笔划线高亮（支持 `==词语==`）+ 想法札记便签框 + 书名出处。适合痛点共鸣。
- `dark`：深邃冷黑渐变 + 磨砂玻璃卡片 + 霓虹发光字与终端窗口指示灯。适合科技硬核、极客自嘲。
- `cinema`：沉浸式电影胶片暗角 + REC红点 + 时间戳 `01:42:18` + 经典黄色双语字幕 + 胶片声轨。适合叙事、对白、情感金句。
- `polaroid`：拍立得经典相纸白框 + 左上角仿真和纸胶带斜贴 + 柔和内嵌相片 + 底部手写签名与印章。适合文艺、生活美学、清欢随笔。
- `tweet`：现代社交卡片 + 圆形头像 + 官方认证蓝V + 锐评金句 + 底部点赞转发互动数据行。适合爆款锐评、社交货币。

### 封面背景主题 (`--theme`)

- `celestial`（默认）：云月星辰品牌风，带有水墨流云、金月与微光。
- `swiss`：瑞士现代平面风，无月亮插画，采用精密网格底纹、十字对准线坐标、几何强调色块。适合硬科技、AI研报、严肃深度特稿。
- `press`：复古报刊社论风，双层细线框、角标括号、报刊细线饰带。适合调查特稿与深度报道。

旧图空、缩略图看不见字：多半拿刊头去当了信息流。封面用 `feed`，竖封用 `briefing`。
