# 预设与版式

颜色默认按星期走，不要让用户选。只有用户点名 `--preset` 才覆盖。

| 星期 | preset | 氛围 |
|---|---|---|
| 一 | `dusk` | 夜空金月 |
| 二 | `twilight` | 暮光奶油 |
| 三 | `paper` | 宣纸朱印 |
| 四 | `frost` | 霜蓝 |
| 五 | `ember` | 烬暖 |
| 六 | `ink` | 墨青 |
| 日 | `dawn` | 浅金 |

| layout | 结构 | 默认比例 |
|---|---|---|
| `feed` | 信息流。大日期 + 星期 + 栏目名 | `2.35:1` |
| `editorial` | 刊头。字在左，月/云在右 | `4:3` |
| `briefing` | 竖版简报。报名 + 日期 + 三条要闻 | `3:4` |
| `divider` | 分割条。大号 `01` + 章节名 | `4:1` |
| `quote` | 金句。大引号 + 作者 + 朱印 | `1:1` |
| `bullet` | 横版清单。胶囊序号 + 要点 | `4:3` |
| `square` | 方图。日期 + 栏目 | `1:1` |
| `poster` / `story` | 旧名，等于 `briefing` | `3:4` |
| `banner` | 宽图；公众号封面请用 `feed` | `16:9` |

旧图空、缩略图看不见字：多半拿刊头去当了信息流。封面用 `feed`，竖封用 `briefing`。
