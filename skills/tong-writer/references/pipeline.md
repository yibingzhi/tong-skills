# Tong Writer 流水线设计与流转规范

## 1. 写作生命周期全景 (4 大核心 Skill)

```text
       [素材/碎念/卡壳]
              │
              ▼
   ┌──────────────────────┐
   │      tong-muse       │  灵感催化与素材挖掘（苏格拉底追问、事实提取、利益冲突提炼）
   └──────────────────────┘
              │  交付《素材档案》
              ▼
   ┌──────────────────────┐
   │     tong-writer      │  长文创作中枢（3切角立意 -> 8段骨架 -> 镜头冷开场 -> 正文 -> 2~3句金句）
   └──────────────────────┘
              │  交付完整正文初稿
              ▼
   ┌──────────────────────┐   联动   ┌──────────────────────┐
   │    tong-humanize     │ <─────> │      tong-title      │
   │  (去AI味扫描+主编终审) │         │  (多平台爆款标题矩阵) │
   └──────────────────────┘         └──────────────────────┘
              │
              ▼
       [高分定稿发布]
```

## 2. 状态与交付契约

- **输入 (Input)**：
  - 用户原始想法、随手笔记，或来自 `tong-muse` 的素材档案（包含客观事实、原发情绪、具象冲突）。
- **创作中枢内部推进**：
  1. `thesis_and_outline`: 明确 1 个推荐切角及 8 段式推进目标。
  2. `cold_open`: 150~250 字动作与实物特写镜头。
  3. `draft_raw`: 手机友好排版短段落正文。
  4. `draft_with_quotes`: 回填 2~3 处穿透性金句后的终稿初版。
- **输出交付 (Output)**：
  - Markdown 格式完整长文初稿，直接供 `tong-humanize` 门禁质检或直接交付用户。
